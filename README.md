# Phishing URL Awareness Checker

## Introduction
This is a simple Python project that checks URLs for possible phishing warning signs.

## Objective
The main objective is to create awareness about phishing URLs and help users identify suspicious links.

## Features
- Checks URL text.
- Identifies suspicious words.
- Detects unusual URL patterns.
- Displays warning messages.

## Technology Used
- Python

## How to Run
1. Install Python.
2. Download the project.
3. Open the project folder.
4. Run `python phishing_checker.py`.

## Disclaimer
This project is for educational purposes only. It checks URL text and does not guarantee that a website is safe.
